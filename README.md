# Портфолио дизайн-студии «СДВИГ»

Адаптивный лендинг для вымышленной дизайн-студии, созданный в рамках 6-дневного интенсива по фронтенду.

## 🚀 Технологии
* **HTML5** — семантическая верстка.
* **CSS3** — Grid, Flexbox, CSS-переменные, кастомные hover-эффекты, `backdrop-filter`.
* **AOS (Animate On Scroll)** — плавное появление секций при прокрутке.
* **GSAP + SplitText** — эффектное появление заголовка по буквам с 3D-поворотом.
* **Three.js** — интерактивный 3D-фон из частиц на главном экране.

## 💡 Что здесь особенного
В проекте реализован сложный **Hover-эффект карточек** с плавным зумом изображения и появлением полупрозрачного оверлея с размытием (`backdrop-filter`). Также добавлен **3D-фон на Three.js**, который реагирует на движение и создает глубину. Все анимации уважают настройки доступности (`prefers-reduced-motion`), а интерактивные элементы имеют видимый фокус для управления с клавиатуры.
